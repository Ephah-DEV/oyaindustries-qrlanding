# Oya Waste Management Limited — One-Page Website

A premium, responsive one-page company profile inspired by the supplied bento-style reference.

## Files
- `index.html` — semantic page structure and company information
- `styles.css` — responsive bento layout, green visual system, typography, gradients and motion
- `script.js` — current-year footer and lightweight reveal animations

## Run
Open `index.html` in a browser. No build process is required.

The Google Fonts stylesheet loads IBM Plex Sans, Manrope and IBM Plex Mono from Google Fonts. If you need a fully self-hosted production build, download and serve the font files locally.

## Notes
- Contact links are clickable.
- Website and location links open in a new tab.
- `prefers-reduced-motion` is respected.
- No fabricated service claims were added beyond the business category supplied by the client.
